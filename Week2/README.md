# Week 2 – PID controller

The Lab 1 timing is replaced by encoder-based PID control: each straight segment and each turn is its own PID loop.

## Files

| File                 | Description                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `PID-controller.qrs` | PID on the encoder distance for straights and on the heading for pivot turns ($K_p = 30$, $K_i = 0$, $K_d = 20$). |
